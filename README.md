## 1. Project Purpose & Use Case

In high-assurance authentication environments, passwords and SMS OTPs are increasingly vulnerable to phishing and SIM swapping. Voice biometrics provides a frictionless biometric factor, but requires presentation-attack defenses to mitigate replay and synthetic-speech attacks.

However, voice authentication faces a critical threat: **presentation attacks** (synthetic speech generated by text-to-speech engines or voice conversion deepfakes). Standard speaker verification models verify identity (*"Does this voice sound like User X?"*), but they cannot distinguish genuine human vocal tract production from high-quality neural synthesis.

This repository implements a **two-stage verification pipeline** that pairs:
1. **RawNet2** for **Presentation Attack Detection (PAD)**: detecting bona fide human speech vs. synthetic spoof attacks.
2. **ECAPA-TDNN** for **Speaker Verification**: matching the acoustic voiceprint against enrolled identity profiles.

## 2. Architecture & Pipeline

```
Voice Input Audio (16 kHz mono)
         │
         ▼
┌────────────────────────────────────────┐
│   RawNet2 Presentation Attack Detection │
│   (SincConv + ResBlocks + GRU)         │
└───────────────────┬────────────────────┘
                    │
           Is audio BONAFIDE?
           ├── NO (SPOOF)  ──► [REJECT AUTHENTICATION: Presentation Attack Detected]
           │                   (Early exit: terminates before speaker verification)
           └── YES (BONAFIDE)
                    │
                    ▼
┌────────────────────────────────────────┐
│     ECAPA-TDNN Speaker Verification    │
│  (speechbrain/spkrec-ecapa-voxceleb)   │
└───────────────────┬────────────────────┘
                    │
        Matches Enrolled Voiceprint?
        ├── NO (IMPOSTOR) ──► [REJECT AUTHENTICATION: Speaker Mismatch]
        └── YES (GENUINE) ──► [VOICE MFA FACTOR PASSES]
```

Detailed architectural diagrams, sequence flows, and failure mode analyses are available in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## 3. Component Responsibilities

The two models maintain strictly separated concerns:

- **RawNet2**:
  - **Presentation Attack Detection (PAD)**: bona fide vs. spoof.
  - Classifies audio as `BONAFIDE` vs `SPOOF`.
  - Targets presentation attacks such as TTS and Voice Conversion.
  - **Does NOT determine speaker identity**.
- **ECAPA-TDNN**:
  - **Speaker verification**.
  - Extracts 192-dimensional speaker embeddings and calculates cosine similarity against an enrolled voiceprint.
  - **Does NOT perform anti-spoofing**.

---

## 4. Voice Factor Boundary Notice

> [!IMPORTANT]
> **Voice Factor Decision vs. Final Authorization**:
> A successful voice factor only indicates that the **voice authentication factor passed**; it does not by itself constitute final user authentication or authorization.
> - `RawNet2 PASS` + `ECAPA-TDNN PASS` $ightarrow$ Voice MFA factor passes.
> - It does **NOT** mean the user is fully authorized.
> - The broader **Adaptive MFA Policy Engine** evaluates this result alongside device health, IP reputation, behavioral risk, and policy rules before rendering the final access decision.

- Python 3.9, 3.10, or 3.11

## 6. Model Checkpoint Configuration

Per security best practices, **large model weights are not committed to Git**.

### 1. ECAPA-TDNN (SpeechBrain)
- Automatically downloaded from Hugging Face Hub (`speechbrain/spkrec-ecapa-voxceleb`) on first initialization.
- Cached locally in `pretrained_models/speechbrain/` (excluded by `.gitignore`).

### 2. RawNet2 (NTU-ROSE Pretrained Weights)
- Download the pretrained checkpoint `pre_trained_DF_RawNet2.pth` (67.25 MB) from the upstream NTU-ROSE release:  
  [https://github.com/NTU-ROSE/RawNet2](https://github.com/NTU-ROSE/RawNet2)
- Place the file in:
  ```
  pretrained_models/rawnet2/pre_trained_DF_RawNet2.pth
  ```
- Or pass the explicit checkpoint path to `RawNet2Detector(checkpoint_path=...)`.

## 8. Enrollment & Verification Workflow

```python
from src.extractors import SpeakerVerifier
from src.pipeline import VoiceBiometricPipeline

# 1. Initialize verifier and pipeline
verifier = SpeakerVerifier(threshold=0.25)
pipeline = VoiceBiometricPipeline(
    speaker_verifier=verifier,
    rawnet2_checkpoint="pretrained_models/rawnet2/pre_trained_DF_RawNet2.pth"  # Optional
)

# 2. Enrollment: Average multiple recordings into a 192-d voiceprint
enrollment_audio = ["path/to/enroll_1.wav", "path/to/enroll_2.wav"]
enrollment = verifier.enroll(enrollment_audio)
voiceprint = enrollment["voiceprint"]

# 3. Authentication: 2-stage verification
result = pipeline.authenticate_factor(
    enrolled_voiceprint=voiceprint,
    test_audio="path/to/test_sample.wav"
)

if result["voice_factor_passed"]:
    print(f"Voice factor PASSED (Similarity: {result['verification_result']['cosine_similarity']:.4f})")
else:
    print(f"Voice factor REJECTED: {result['rejection_reason']}")
```

## 9. Benchmark Results Summary

### ECAPA-TDNN Speaker Verification (Phase 1 Benchmark)
Evaluated across 60 pairwise trials (30 genuine, 30 impostor) under varying acoustic conditions:
- **Genuine Mean Similarity**: `0.6125` (Range: `[0.3105, 1.0000]`)
- **Impostor Mean Similarity**: `0.1234` (Range: `[0.0218, 0.2234]`)
- **Observed Separation Gap**: `+0.0871` (Lowest Genuine `0.3105` − Highest Impostor `0.2234`)
- **Observed Research EER**: `0.00%`
- **Mean Verification Latency**: `34.72 ms` (RTX 3050 GPU)
- Detailed report: [docs/ECAPA_SPEAKER_VERIFICATION.md](docs/ECAPA_SPEAKER_VERIFICATION.md)

### RawNet2 Presentation Attack Detection (ASVspoof 2019 Benchmark)
Evaluated on a deterministic 1,000-utterance subset (500 bona fide, 500 spoof) across 13 attack types (A07–A19):
- **Equal Error Rate (EER)**: `32.60%` (Threshold: `-4.4516`)
- **ROC-AUC**: `0.7339`
- **Spoof Rejection @ EER**: `67.40%`
- **At Argmax Threshold (`-0.6931`)**: Blocks `88.40%` of spoof attacks (APCER: `11.60%`, BPCER: `57.40%`)
- **Mean Per-File Latency**: `23.57 ms` (RTX 3050 GPU)
- Detailed report: [docs/RAWNET2_ANTISPOOFING.md](docs/RAWNET2_ANTISPOOFING.md)

## 10. Research Qualifications & Limitations

1. **Not a Production Security Guarantee**:
   - The 0.00% observed EER for ECAPA reflects performance on our controlled research benchmark. It is **not** an absolute guarantee of zero false accepts in production.
   - RawNet2 is an established research baseline. Its 32.60% EER highlights known domain-mismatch challenges when raw time-domain models encounter varied microphone hardware and ambient room noise.
2. **Defense-in-Depth**:
   - Voice biometrics should operate as one factor in an adaptive multi-factor ecosystem, never as a sole authentication mechanism.

---

## 11. Security & Privacy Guidelines

- **Zero Biometric Audio in Repository**: In compliance with privacy principles, this repository contains zero human voice recordings (`.wav`, `.m4a`, etc.).
- **Sanitized Research Artifacts**: All committed benchmark CSVs contain anonymized tokens and public ASVspoof identifiers, with zero local paths or personally identifying references.
- **Model Checkpoint Hygiene**: Checkpoints are excluded by `.gitignore` to prevent repository bloat and dependency coupling.
