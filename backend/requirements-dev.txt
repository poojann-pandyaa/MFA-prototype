# onnx must be >= 1.18: the 1.17.0 macOS universal2 wheel bundles an
# abseil/protobuf runtime that clashes with tensorflow 2.20's, and the
# process aborts (SIGABRT) or deadlocks the moment both are imported
# together on arm64.
onnx>=1.18
# tf2onnx is NOT listed as a requirement on purpose: its metadata still
# pins protobuf~=3.20, and installing that downgrades protobuf below what
# tensorflow 2.20 (>=5.28) and mediapipe need, breaking both at import
# time. Its own code runs fine on protobuf 5.x, so install it separately,
# without its dependencies, when you need to run the export:
#     pip install --no-deps tf2onnx
